Book Lending App 

Email and password sign-up and sign-in.
Users add, edit and delete books (title, author, copies).
Users search and browse the books that are available.
When a user borrows a book, the app sets a 14-day due date.
The user marks the book returned, and the copy count updates.
On the dashboard, users see their current loans and any overdue ones.
The app needs three tables: Users, Books and Loans.
