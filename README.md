# Book lending - v1

Book Lending App 

Email and password sign-up and sign-in.
Users add, edit and delete books (title, author, copies).
Users search and browse the books that are available.
When a user borrows a book, the app sets a 14-day due date.
The user marks the book returned, and the copy count updates.
On the dashboard, users see their current loans and any overdue ones.
The app needs three tables: Users, Books and Loans.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
